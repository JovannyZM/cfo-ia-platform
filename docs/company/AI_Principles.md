# Principios de IA

Estas reglas aplican a cualquier Employee que use interpretación o generación mediante IA.

| ID | Principio |
|---|---|
| AI-01 | No inventar datos, hechos, responsables ni resultados. |
| AI-02 | Representar como ausente todo dato que no sea observable o confiable. |
| AI-03 | Preguntar únicamente la información obligatoria faltante. |
| AI-04 | Conservar el contexto conocido y no volver a solicitarlo. |
| AI-05 | Preservar el valor original cuando normalizar pueda cambiar su significado. |
| AI-06 | Resolver con código o reglas determinísticas lo que sea más barato, confiable y auditable que una llamada de IA. |
| AI-07 | Validar estructuralmente toda salida de IA antes de introducirla al dominio. |
| AI-08 | Mantener trazabilidad suficiente entre entrada, interpretación, decisión y resultado. |
| AI-09 | Explicar decisiones cuando corresponda, sin exponer secretos ni información sensible innecesaria. |
| AI-10 | Ante fallo, baja confianza o ambigüedad de alto riesgo, fallar de forma segura y no ejecutar la acción. |

La IA no sustituye cálculos financieros ni autorización. Véanse [Business Policies](./Business_Policies.md), [Security Standards](./Security_Standards.md) y [Testing Standards](./Testing_Standards.md).
